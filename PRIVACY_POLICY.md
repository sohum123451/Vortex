# Privacy Policy

**Effective Date:** September 1, 2026  
**Bot Name:** Vortex ("the Bot", "we", "us", or "our")  
**Website:** [https://vortex-bot-mmha.onrender.com](https://vortex-bot-mmha.onrender.com)

Vortex is dedicated to respecting and protecting the privacy of our users. This Privacy Policy explains what information we collect, how it is stored, and your rights regarding your data.

---

## 1. What Information We Collect
To provide bot features and web dashboard management, Vortex collects and processes only minimal, non-personally identifiable information (non-PII):

* **Discord IDs**: Unique snowflake identifiers for Discord Users, Guilds (servers), Channels, and Roles to manage permissions, moderation histories, and configuration settings.
* **Economy & Leveling Records**: Experience points (XP), user levels, virtual wallet/bank balances, and RPG inventory counters.
* **Server Configurations**: Custom server prefixes, announcement channels, level-up message templates, and ticket desk settings.
* **Moderation Audit Logs**: Warning records, active timeout/ban timers, and staff audit notes strictly for server security.
* **OAuth2 Authentication Data**: When logging into the web dashboard via Discord OAuth2, we temporarily retrieve your user avatar, username, and guild administrator permissions to authorize dashboard access. We never access passwords, emails, or personal payment methods.

---

## 2. How We Use Your Information
All collected data is utilized exclusively to maintain bot functionality:
* Executing custom server prefix resolution for commands.
* Rendering leaderboards, member ranks, and virtual currency transfers.
* Logging disciplinary moderation actions for server staff.
* Authenticating server management access on the web dashboard.

---

## 3. Multi-Cloud AI & Data Sharing
* **No Sale of Data**: We **never** sell, rent, trade, or share user data with third-party advertisers or data brokers.
* **Ephemeral AI Prompts**: When users execute AI commands (`&nemotron`, `&deepseek`, `&chat`, `&imagine`), only the text prompt is sent to the respective inference provider (NVIDIA NIM, Groq, Google Cloud, Pollinations). No Discord user tokens, email addresses, or server membership details are passed to AI providers.
* **No AI Model Training**: User data is not used by Vortex to train proprietary machine learning models.

---

## 4. Data Security & Storage
* All server configurations, economy records, and leveling metrics are stored in secured, isolated database files (`*.db`) hosted in the cloud.
* Access to production databases is strictly restricted to authenticated bot processes with encrypted SSL connections.

---

## 5. User Rights & Data Deletion (GDPR / CCPA)
You have the right to request deletion of your stored data at any time:
* **User Data Removal**: Users can request complete purging of their economy, leveling, and warning records by contacting the bot administrator.
* **Guild Data Removal**: Removing Vortex from a Discord server removes active listeners. Server administrators can request complete deletion of server prefix and configuration records upon removal.

---

## 6. Updates to this Policy
We may update this Privacy Policy periodically to reflect new features or regulatory requirements. Any updates will be reflected in the official repository and web dashboard.

---

*For data deletion requests or privacy inquiries, contact the Vortex administration team.*
