# Privacy Policy

Your privacy is important to us. This Privacy Policy details how **Vortex** (the "Bot") collects, stores, and uses data from Discord users and servers (guilds).

---

## 1. What Data We Collect
To function properly, the Bot collects and processes the following non-personally identifiable information (non-PII):
* **User & Guild IDs**: Discord-assigned unique identifiers for users and servers to manage permissions, leveling systems, and server configuration.
* **Leveling/XP Information**: Experience points, level counters, and coin balances associated with User and Guild IDs (stored in local database files).
* **Analytics Data**: Anonymized message counts and activity timestamps to generate server usage charts (if enabled).
* **Custom Command Configuration**: Text inputs and triggers set up by server administrators.
* **Support Ticket Metadata**: Channel IDs and ticket states to manage moderator assistance queues.

## 2. How Data is Used
All collected data is used exclusively to deliver the Bot's core features:
* Storing currency and inventory for the **Economy** cog.
* Awarding experience points and levels for the **Leveling** cog.
* Logging moderator actions (warns, mutes) for server security.
* Powering support tickets and general utility configurations.

## 3. Data Storage & Security
* **No Third-Party Sharing**: We do not sell, trade, rent, or share any user or server data with third parties.
* **Local Database**: All data is stored in localized SQLite database files (`*.db`) on the host system.
* **AI Integrations**: When you interact with AI features, the text of your prompt is sent to external API providers (Gemini, Groq, OpenAI) to generate a response. No user IDs, guild IDs, or account information are shared with these APIs.

## 4. Data Retention & Deletion
* Server administrators can request database clears using internal bot commands.
* If you want your personal leveling/economy data or server configurations permanently deleted from the Bot's local database, please contact the Bot host or server owner.

## 5. Policy Updates
We may update this Privacy Policy from time to time. Continued use of the Bot constitutes acceptance of any updates.

---

*For data removal requests or privacy concerns, please contact the administrator hosting this bot instance.*
